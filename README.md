# 📝 TO Do Flow

**TO Do Flow** is a simple, clean, and user-friendly desktop task management application developed using **C++ and Raylib** as part of a Data Structures project.

The application helps users organize daily tasks, manage schedules, and improve productivity through an intuitive graphical interface.

## ✨ Features

- Clean and modern dashboard
- Easy task management
- Interactive calendar for date selection
- Custom time picker with hour, minute, and second support
- Real-time clock display
- Interactive time selection dial
- Light and Dark mode
- Simple and user-friendly graphical interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| C++17 | Core application development |
| Raylib | Graphical user interface |
| Data Structures | Task organization and management |
| OpenGL | Graphics rendering |
| MinGW / GCC | Compilation |

## 🚀 Getting Started

### Prerequisites

- C++17 compatible compiler
- Raylib library
- MinGW/GCC
- Windows operating system

### Build

Open a terminal in the project directory and run:

```powershell
g++ -std=c++17 main.cpp views.cpp dialogs.cpp -o TO_Do_Flow.exe -lraylib -lopengl32 -lgdi32 -lwinmm
```

### Run

```powershell
.\TO_Do_Flow.exe
```
